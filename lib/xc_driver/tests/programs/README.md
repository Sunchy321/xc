# X 程序语料

一文件一用例的可执行测试包：每个 `.x` 文件都会经 `xc_driver::run_source`
完整管线（解析 → 检查 → 降级 → 校验 → 执行）运行一次。

## 运行

    cargo test -p xc_driver --test programs

（`cargo test --workspace` 亦包含。）

## 用例约定（新增功能必须遵循）

- **一个 `.x` 文件 = 一个用例**；文件名即用例名（kebab-case）。
- 期望输出用注解写在文件内，按顺序与 `print` 输出逐行对应：

      // expect: 1
      // expect: 2

- 期望运行期失败的用例写 `// error:` + 错误消息子串：

      // error: division by zero

- 两者必须至少其一——无注解的文件会被测试拒绝（防止空用例）。
- `// expect:` 匹配整行输出；`// error:` 匹配错误消息子串。
- 用例只允许依赖已裁定的语言语义；实现暂态（如无类型检查阶段的动态行为）
  不要写成用例。

新语言特性落地时：在里程碑验收测试之外，于此目录补 `.x` 用例作为长期回归
语料。编译器内部的降级形态断言（快照）放 `xvm/src/lower.rs` 的测试模块，
不放在这里——这里只关心可观察行为。
